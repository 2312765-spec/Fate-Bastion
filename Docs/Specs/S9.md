# S9. Lưu trữ

> Tách từ `Docs/Dac ta ky thuat.docx` v1.3 (05/10/2026). Khi thiết kế thay đổi: sửa file này trước, rồi mới sửa code.

**Mục tiêu:** lưu toàn bộ tiến trình ngoài trận an toàn, không mất dữ liệu khi tắt game hoặc máy sập giữa chừng.

**Dữ liệu – SaveData:**

```text
{
  "version": 1,
  "gems": 1200,
  "pityCounter": 17,
  "collection": { "hero_cung_thu": 3, "hero_long_vuong": 1 },
  "deck": ["hero_cung_thu", "hero_phu_thuy_lua", "hero_linh_bang", "hero_thanh_nu", "hero_long_vuong"],
  "ownedEver": ["hero_cung_thu", "hero_long_vuong"],
  "levelProgress": { "level_1": 3, "level_2": 2 },
  "endlessBest": 23,
  "tutorialDone": true,
  "settings": { "master": 0.8, "music": 0.6, "sfx": 0.8, "cameraShake": true, "skipConfirm": true }
}
```

**Thành phần:** `SaveService` (đọc/ghi bằng Newtonsoft Json tại `Application.persistentDataPath/save.json`). Các service khác chỉ làm việc với `SaveData` trong bộ nhớ và gọi `SaveService.Save()`. Bản 1 tháng chỉ có `version` = 1, chưa cần SaveMigrator.

**Ghi an toàn:** ghi ra `save.tmp` → nếu `save.json` đã tồn tại thì `File.Replace(tmp, json, bak)`, nếu chưa (lần lưu đầu) thì `File.Move(tmp, json)`. Không bao giờ ghi đè trực tiếp lên `save.json`.

**Thời điểm lưu:** sau mỗi thao tác của S8 (quay, ghép, đổi deck); khi màn hình kết quả trận hiện ra; khi đổi cài đặt; trong `OnApplicationQuit`. Không lưu trạng thái giữa trận.

**Đọc khi mở game:** đọc `save.json` → lỗi thì thử `save.bak` → vẫn lỗi thì tạo dữ liệu mới từ `StarterSettings` và báo cho người chơi.

**Trường hợp đặc biệt:**

- `heroId` trong file không còn tồn tại trong game (đã xóa tướng): bỏ qua và ghi log, không làm hỏng cả file.
- Deck chứa tướng không hợp lệ: thay bằng tướng khởi đầu còn trống, báo người chơi kiểm tra lại deck.
- Bảng Debug (F1, **do B làm** – TRACEABILITY B-16; A chỉ cung cấp `SaveService.Delete()`/`Save()` để bảng gọi): xóa save, cộng Ngọc, nhận một tướng bất kỳ, nhảy wave, bất tử Thành, tốc độ ×5. Toàn bộ code bọc trong `#if UNITY_EDITOR || DEVELOPMENT_BUILD`. Bản nộp là build Release (không có Debug); buổi bảo vệ chạy bản Development build.

**Tiêu chí hoàn thành:**

- ☐ Test lưu rồi đọc lại cho kết quả giống hệt.
- ☐ Test lần lưu đầu tiên (chưa có `save.json`) không lỗi.
- ☐ Test file hỏng → dùng `save.bak`; cả hai hỏng → tạo mới, không crash.
- ☐ Tắt game ngay sau khi quay: mở lại có đủ tướng vừa quay và Ngọc đã trừ.
